# Roadmap

## v0.1 — Foundation (implemented)

- Searchable concept library with categories and saved concepts
- Three live experiments with linked controls, visualizations, and metrics
- Four explanation layers per live experiment
- Introductory paths and clearly labeled future-module previews
- Separated concept metadata, teaching content, and numerical computation
- Numerical regression checks

## Next — Strengthen the learning experience

- Extract each experiment into its own module and introduce an experiment registry
- Add stable concept URLs and shareable parameter states
- Make prediction prompts interactive, then show evidence-based feedback
- Add accessible text or table alternatives for canvas charts
- Review color contrast, mobile interactions, and reduced-motion behavior
- Add explicit parameter comparison and cross-validation demonstrations

## Expand the collection

1. Gradient descent: learning rate, curvature, and convergence
2. Embedding geometry: vector operations, cosine similarity, and projection distortion
3. Attention: inspect Q/K/V and intermediate matrices on a tiny example
4. RAG: inspect retrieval results and how evidence changes an answer
5. Forecast evaluation: temporal splits, leakage, and changing patterns

## Product choices to resolve

Primary audience, English versus bilingual content, contributor workflow, license, and how much progress tracking is useful. Keep the first versions focused on understandable experiments before adding accounts or a tutor.
